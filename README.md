# Кантип?

Кыргызстанда документтерди жана мамлекеттик кызматтарды кантип алууну кадам-кадамы менен түшүндүргөн сайт.

Сайт [Astro](https://astro.build) менен жасалган (HTML, CSS, JavaScript/TypeScript). Курулгандан кийин ал жөнөкөй статикалык файлдарга айланат, ошондуктан ылдам иштейт, Google'да жакшы табылат жана акысыз хостингге жайгаштырылат.

## Иштетүү

```bash
npm install        # бир жолу гана
npm run dev        # http://localhost:4321 дарегинде ачылат
npm run build      # даяр сайт dist/ папкасына чыгат
```

## Жаңы жол көрсөткүч кошуу

1. `src/content/guides/` папкасындагы каалаган `.md` файлдын көчүрмөсүн алыңыз.
2. Файлдын атын латын тамгалары менен жазыңыз (мисалы, `bala-bakcha.md`). Бул ат беттин дареги болот: `/jol/bala-bakcha/`.
3. Талааларды толтуруңуз: `title`, `summary`, `category`, `documents`, `steps` ж.б.
   `category` төмөнкүлөрдүн бири болушу керек: `dokumentter`, `uy-bulo`, `pensiya-jolokpul`, `biznes`, `mulk`, `den-sooluk`.
4. `---` белгисинен кийин кошумча текст жазсаңыз болот, ал бетте көрсөтүлөт.
5. `npm run build` буйругу ката көрсөтсө, кайсы талаа туура эмес толтурулганын жазат.

Темалардын тизмеси `src/data/categories.ts` файлында, сайттын аты жана байланыш шилтемеси `src/data/site.ts` файлында турат.

## Жаңыртуу

Сайт https://kantip-kg.netlify.app дарегинде турат. Бир нерсе өзгөрткөндөн кийин ушул буйрукту аткарыңыз:

```bash
npm run deploy
```

## Башка жерге чыгаруу (акысыз)

Эң оңой жолу – **Netlify** же **Cloudflare Pages**:

1. Долбоорду GitHub'га жүктөңүз.
2. Netlify же Cloudflare Pages'те ошол репозиторийди тандаңыз.
3. Build command: `npm run build`, output папкасы: `dist`.
4. `SITE_URL` деген чөйрө өзгөрмөсүнө сайттын дарегин жазыңыз (мисалы, `https://kantip.kg`), жана `public/robots.txt` файлындагы даректи да ошого алмаштырыңыз.

## Маанилүү

Жол көрсөткүчтөрдөгү маалымат жалпы мүнөздө жазылган. Сайтты элге чыгараардан мурун ар бир жол көрсөткүчтү расмий булактар менен текшерип, `updated` талаасындагы күндү жаңыртыңыз.
